# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-27

### Added

- Multi-step onboarding wizard with new program and resume options
- Daily dashboard with circular progress ring
- Activity checklist grouped by category with expandable instructions
- Streak tracking and display
- Daily notes with debounced auto-save
- Weekly educational content and goals
- Program log with week-grouped history
- Settings page with notification, unit, and reset controls
- Bottom navigation with smooth active states
- Data-driven 18-week Core Rehabilitation Program
- Repository pattern storage layer (localStorage)
- Program engine for day/week/progress calculations
- Complete TypeScript types for current and future features
- PWA manifest and service worker
- Custom design system with green/blue color scheme
- Celebration animation on daily completion
- Full documentation suite

# User Stories

## Epic: Onboarding

- As a new user, I want to see a welcoming introduction so I understand what the app does.
- As a new user, I want to start a new program so I can begin from Day 1.
- As an existing user, I want to resume my program mid-way so I don't lose my progress.
- As a user, I want to set my reminder preferences so I receive timely notifications.

## Epic: Daily Dashboard

- As a user, I want to see what I need to do today so I never wonder about my tasks.
- As a user, I want to see my current week and day so I know where I am in the program.
- As a user, I want to check off activities as I complete them so I track my daily work.
- As a user, I want to see detailed instructions for each activity so I perform them correctly.
- As a user, I want to see my completion percentage so I know how much is left today.
- As a user, I want to see my streak so I stay motivated.
- As a user, I want to write daily notes so I can reflect on my experience.
- As a user, I want to see weekly educational content so I learn as I progress.
- As a user, I want a celebration when I complete a day so I feel accomplished.

## Epic: Program Log

- As a user, I want to review past days so I can see my history.
- As a user, I want to see which activities I completed on any given day.
- As a user, I want logs grouped by week for easy navigation.

## Epic: Settings

- As a user, I want to adjust my reminder times so they fit my schedule.
- As a user, I want to choose between metric and imperial units.
- As a user, I want to reset my program if I need to start over.

## Epic: Measurements (Planned)

- As a user, I want to record weekly body measurements so I track physical changes.
- As a user, I want to see my measurement progress on charts.
- As a user, I want to take progress photos alongside measurements.

## Epic: Achievements (Planned)

- As a user, I want to earn badges for milestones so I feel rewarded.
- As a user, I want to see all my achievements in a gallery.

## Epic: Reports (Planned)

- As a user, I want weekly summary reports so I understand my progress.
- As a user, I want to export my progress as a PDF for my healthcare provider.

## Epic: Cloud Sync (Planned)

- As a user, I want my data synced across devices so I can use any device.
- As a user, I want to create an account so my data is protected.

## Epic: Clinician Portal (Planned)

- As a clinician, I want to monitor patient progress remotely.
- As a clinician, I want to assign custom programs to patients.

## Epic: AI Coaching (Planned)

- As a user, I want personalized coaching based on my progress.
- As a user, I want the program to adapt to my capabilities.
